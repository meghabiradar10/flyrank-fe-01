# FlyRank AI – Frontend AI Engineering

This repository contains my work for the FlyRank AI Frontend AI Engineering assignment.

## Objective

The goal of this assignment is to practice AI-assisted frontend engineering workflows using Claude Code and modern development tools.

## Tech Stack

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Claude Code
- VS Code

## Development Workflow

1. Plan the task before implementation.
2. Use Claude Code for AI-assisted development.
3. Review generated code before accepting it.
4. Follow clean and readable coding practices.
5. Use Git with Conventional Commits.
6. Keep documentation updated.

## Coding Conventions

- Use meaningful variable and function names.
- Keep functions small and focused.
- Prefer readable and maintainable code.
- Avoid unnecessary duplication.
- Write clear comments only when they add useful context.
- Test changes before committing them.
